# LearningPython
Hands on for learning basics to advanced concepts in Python.

Python projects are generally named in kebab case just like the one we have now python-for-ai
Workspace is like a bookmark for your project. So it will leave the project where you left off and can open it in the as is condition 

Virtual Environment -- private copy of python for each project 
to activate this python project we use the command - source <<venv_name>>/bin/activate

Packages -- pre-written code that others have created for us to use
pip - Python's package manager.
to download and install a particular package we use the command
  pip install requests
  pip is connected to Python Package Index (PyPI) where developers share their code. Downloaded the requests page on to our .venv

Single line comments are starting with #
For block comments we use """ """

Logical operators are mentioned as and, or, not

Formatted Strings -- making strings dynamic 

Normally if you want to print your name  - print("Hi my name is srividya")
now if we want to change the name or make this print statement work for each of the name change we do then 

name = "Srividya"
print_statement = f"""Hi My name is {name}"
this way the value in the variable name will be appended to the string and used.
